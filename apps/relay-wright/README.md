# relay-wright

banto-industrial 内の PLC 自動書き込みアプリ（Tauri + banto テンプレート由来）。
タグレジストリ（banto-tags）で定義した読み取り値を条件に、ユーザーが
設定したルールに従って別のPLCデバイスへ値を自動書き込みする。
