# relay-wright

banto-industrial 内の PLC 自動書き込みアプリ（Tauri + banto テンプレート由来）。
タグレジストリ（banto-tags）で定義した読み取り値を条件に、ユーザーが
設定したルールに従って別のPLCデバイスへ値を自動書き込みする。

## 開発用サーバー（`relay-wright-serve`）について

Tauri を使わずに REST + 静的配信だけを動かす開発用バイナリ
`relay-wright-serve`（`core/src/bin/relay-wright-serve.rs`）は、**既定で
`0.0.0.0`（全インターフェース）に bind** する。LAN 越しの動作確認をしやすく
するための開発用デフォルトで、デスクトップ版 Tauri アプリの LAN モード
既定（`127.0.0.1`）とは異なる。閉域 LAN 内であっても、起動したままの
ホストはそのネットワーク上のどこからでも到達可能になる — **開発・
プレビュー用途に限定し、本番相当の公開・常時稼働はしないこと**。bind
アドレスは環境変数 `BANTO_BIND` で変更できる。
