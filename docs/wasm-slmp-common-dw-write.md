# SLMP WASM D/W 書込み境界

Hub は署名検証済みの write-v1 guest を明示選択した接続でのみ、SLMP の連続した D または W の `u16` 書込みを受け付ける。通常の読取り専用 loader は write 宣言を拒否する。実際の配置先、信頼鍵、接続設定を整えるまで、本番での有効化は行わない。

## 接続設定と互換性

保存済み設定キー `d_u16_write_mode` と `d_u16_write_allowlist` を維持する。初期状態は `disabled` と空リスト。`enabled` と明示リストの両方が必要で、旧設定 `D3010-D3013` から W は許可されない。D と W に別の有効化スイッチは設けない。

```text
d_u16_write_mode=enabled
d_u16_write_allowlist=D3010-D3013,W1A-W1F
```

D 番地は10進、W 番地は16進の大文字で記す。同一区間の両端は同じエリアとし、各エリア内の区間は昇順で重複させない。区間は最大16件、各区間は最大960語、設定文字列は最大256バイト。D3000/D3001を含む区間と、それらにまたがる要求は拒否する。空リスト、欠番、重複、逆順、エリア混在、非整数・非有限値、`u16` 範囲外の値を含む要求では、一部だけを送信しない。

Hub は保存設定、タグの正規アドレスとエリア、幅、型、値、要求全体の連続性と許可範囲を送信前に独立検査する。guest は同一接続で取得した型式・機器別 SD 情報で全範囲を確認する。範囲不明は許可と見なさない。既存のタグ書込み認可、write control、broker 直列化、監査、署名と loader の検証を引き続き適用する。送信後のタイムアウト・切断・不正 ACK は結果不明として扱い、自動再送しない。送信前の全件検査は PLC 側の原子的更新を保証しない。

初期の guest 対象は StandardR の D/W、StandardQ の内部 W、および従来の D 読書きである。Q25PRH の W、bit、word-bit、timer/counter、`u16` 以外の書込みはこの許可設定で広げない。bit は**読取りのみ**明示受入れ、WIT Bool を Hub の Bit 値へ変換する。収集では true/false を 1/0・Good、機器拒否を値なし・Bad とする。別型の WIT 値は拒否する。従来の数値8型読取りとその f64 投影は維持する。

CI は WASM guest の固定コミットを独立ビルドし、WIT/world を照合してループバック試験を実行する。旧 D 専用 guest の回帰も別に残す。模擬試験には実 PLC 通信、実際の本番有効化、信頼鍵の配置を含まない。
