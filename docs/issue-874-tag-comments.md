# Issue #874: タグコメント

状態: ローカル実装（2026-10-27）。

PLC・演算・内部・DB の全タグに共通する表示用 `comment` を追加する。タグの ID・名前・アドレス・値収集・参照解決には使用しない。長さは Unicode 文字数で 500 文字以下とし、改行と前後の空白を保持する。空は `""` として保存・返却する。

既存行は追加的な SQLite migration の既定値 `""` で読み込む。作成 payload の省略は空とする。更新 payload の省略は既存値を保持し、明示的な `""` はクリアする。REST 更新の `null` は省略と同じ扱いで、設定 JSON の `null` は不正値として拒否する。

新しい設定 JSON 書き出しにはコメントを含める。旧 JSON にコメントがない場合、新規タグは空で作成し、既存タグの更新では保存済みのコメントを保持する。

タグ CSV 出力には `comment` 列を末尾に追加する。入力は従来の 18 列と新しい 19 列を受け付ける。従来形式で既存タグを更新するときはコメントを保持し、新形式の空欄は明示的なクリアとして扱う。
