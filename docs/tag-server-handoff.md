## 第2セッションの調査結果（マニュアル v6.0.17 一次情報、設計 doc 反映済み）

タグ編・インターフェース編・スクリプトガイドの主要13ページを取得し、
以下を doc へ反映:

- 3層構造の対応を精緻化（§1.1）: Unit = PLC毎の接続設定、**Folder =
  更新周期のグループ化**（+ マルチドロップ経路設定、ネスト不可）、
  Tag = デバイス1点 + 型変換/工学値変換フィルタ — I1 の
  `PlcConnection`/`CollectionGroup`/`Tag` と役割まで正確に一致。
  タグパス区切りも `.` で一致（例 `U01.F01.T01`）
- タグ種別を対応表へ追加（§1.1）: スタティック / アクティブ（`#` 前置の
  直接アドレス。本設計は意図的に非対応）/ エイリアス（CSV 定義ファイル、
  読み書き両対応。安定 ID で代替）/ ネットワーク（旧方式、後継は IPLink
  サーバーユニット）/ システムタグ（`/api/v1/status` で代替）
- 初版 §1.1 の「Panel IF」の正式名は **IPLink**: 同社独自 TCP/IP
  プロトコル + ActiveX クライアントライブラリ。公開仕様はサーバー設定
  （有効化・IP 最大3・ポート・タイムアウト）まで、ワイヤ仕様・購読意味論は
  非公開 → §5.2 の WS 購読は独自設計で確定してよい（注記済み）
- スクリプト言語の正式名は「ロボスクリプト」。SC1 / SC2 / 演算式構文の
  3構文（演算式構文が本設計の演算タグ式に最も近い）。**SC2 オペレータ
  一覧を全量取得**（§4.2 に反映）: 四則 + 比較 + 論理 + ビット `&` `|`。
  暗黙型変換が多い（`"1"+2`=3、`&` は文字列結合兼用、T/F→1/0）→ 本設計は
  登録時型検査・暗黙変換なしと明記。ビット抽出は `&` マスクで実需要あり →
  `bit(tag, n)` 組み込み関数を提案（§10-12 に材料追記）
- インターフェース: OPC DA1.0/2.0、DDE（EX_Table/CF_Text）、IPLink、
  Redundancy（メイン/サブ二重化 — 本設計非スコープと明記）
- FA-Server 本体機能（ロガー・日報・FTP・タグブリッジ・外部アプリ実行・
  SQL・スクリプト）は §2 の非スコープ判断と整合、変更不要

取得済みページの生 HTML はセッションの scratchpad にのみ保存

## オーナー決定済み（再確認不要）

1. タグサーバーを独立アプリとして設計先行する（実機に依存しない期間の作業）
2. 外部 IF は REST / WebSocket / MQTT / gRPC。OPC UA は後回し、OPC DA/DDE は追わない
3. ロガー・日報・帳票機能は作らない（記録は ChronoGazer の専管）
4. **中央レジストリ構想**: 今後の関連アプリ（SCADA 等)は自前でタグ定義せず、
   タグサーバーの catalog をバインドして使う
5. アクション機能（スクリプト・メール等）は不要
6. **演算タグ・内部タグはタグサーバー側で一元実装**（クライアント各自ではなく）
7. **オンライン動的変更**を FA-Server との差別化要件とする
   （FA-Server は稼働中の構成変更ができない、というのがオーナーの不満点）
8. **アプリ名は `banto-hub`**（§10-1 解決。配置は `apps/banto-hub/`）
9. **書き込み受付は REST / gRPC の2経路のみ**（WS は購読専用、MQTT set
   なし — §10-5 も同時解決）
10. T0/T2 系の未決を一括決定（§10-2/3/6/7/8）: I1 `tags` 列追加1回・
    I6 broker 抽出・utoipa・ポート 8722 + 50051・tstore 記録あり保持7日
11. 2026-08-05 決定分（§10-4/9/10/11）: MQTT 組み込みブローカーは将来
    実装・当面保留 / リネームは警告のみ（オンライン変更の影響はユーザー
    責任）/ **PLC アドレスは catalog 既定に含める**（catalog:full スコープ
    廃止）/ SDK は T1 完了時起票・SCADA 具体化と同時着手（前倒し可能性
    あり）
12. 式文法確定（§10-12、2026-08-05）: 最小セット + `bit(tag, n)`、文字列
    演算なし・暗黙型変換なし → **§10 のオーナー判断待ちは全件クローズ**
13. **管理 UI の共通利用**（2026-08-05、§3.1）: UI 実体は hub 配信の1つ
    のみ。既存 Tauri アプリは「タグサーバー管理」メニューから hub URL を
    WebviewWindow で開く（コンポーネント組み込みはしない — バージョン
    ずれ排除）
